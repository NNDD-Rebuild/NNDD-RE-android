# NNDD-RE Android

[NNDD-rebuild](https://github.com/your-repo/NNDD-rebuild)（Electron版）のライブラリをAndroidから視聴するクライアントアプリ。

## 必要なもの

- **PC側**: NNDD-rebuild が起動済みで、HTTPサーバーの外部許可がONになっていること
- **Android**: API 26 (Android 8.0) 以上
- **ネットワーク**: PCとAndroid端末が同じLANに接続されていること

## PC側の準備

NNDD-rebuild を起動 → 設定 → HTTPサーバー → **外部許可: ON**

## インストール

[Releases](../../releases) から最新の `app-debug.apk` をダウンロードしてインストール。

> 初回インストール時は「提供元不明のアプリ」の許可が必要。

## 初期設定

1. アプリを起動するとサーバー設定画面が開く
2. 以下のいずれかでサーバーを設定:

| 方法 | 操作 |
|------|------|
| 手動入力 | PCのIPアドレスとポート(デフォルト: 12345)を入力 |
| QRコード | NNDD-rebuild側で表示したQRをスキャン |
| 自動検出 | 「自動検出」ボタンでLAN内のサーバーを自動探索 |

3. **接続テスト** → 「ライブラリへ」

## 使い方

### ライブラリ画面

| 操作 | 説明 |
|------|------|
| 上部タブ | フォルダ / タグ でフィルタ |
| 検索バー | タイトル・タグで絞り込み |
| ソートボタン | 追加日・再生数・タイトルで並び替え |
| グリッド/リスト | 右上のアイコンで表示切替 |
| 動画タップ | 再生画面へ遷移 |

### 再生画面

| 操作 | 説明 |
|------|------|
| タップ | コントロール表示/非表示 |
| 端末回転 | 縦/横画面自動切替 |
| シークバー | 任意の位置に移動 |
| ←→ボタン | 設定したスキップ秒数で前後に移動 |
| コメント | ニコニコ動画互換スタイルで表示 |

### コメントフォントのカスタマイズ

設定画面 → フォント管理 → TTF/OTFファイルを追加するとコメントフォントを変更可能。

## 設定項目

| 項目 | 説明 |
|------|------|
| サーバーIPアドレス | NNDD-rebuildが動作するPCのLAN IP |
| ポート番号 | デフォルト: 12345 |
| スキップ秒数 | 再生画面の←→ボタンでスキップする秒数 |
| コメントフォント | コメント表示に使用するフォントファイル |

## トラブルシューティング

**接続できない**
- PCとAndroidが同じWi-Fiに接続されているか確認
- NNDD-rebuild の HTTPサーバー外部許可がONか確認
- Windowsファイアウォールでポート12345が許可されているか確認

**コメントが表示されない**
- NNDD-rebuild側でコメントデータが取得済みか確認

**動画が再生されない**
- ストリーミング中はWi-Fi接続が必要（モバイルデータでは帯域不足の場合あり）
